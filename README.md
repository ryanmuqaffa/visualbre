# Visual Stock

Aplikasi laporan stok per jetty (R, J, U, K, TCT) dalam satu file HTML.
Isian tersimpan di browser masing-masing, tidak dikirim ke server.

Alamat: https://visualbre.work.gd

## Cara pakai singkat
1. Pilih tanggal dan Shift 1 atau Shift 2.
2. Isi tonase dan keterangan per jetty.
3. Lihat laporan, lalu Kirim lewat WhatsApp atau Telegram.

Tanggal di keterangan: tulis `16,17,18. treatment` untuk hasil `( 16, 17, 18 Okt ) Treatment`.
